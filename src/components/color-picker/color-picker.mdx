## Quick Start

```javascript
import ColorPicker from "carbon-react/lib/components/color-picker";
```

`ColorPicker` is controlled: pass the selected colour as `value` and update it from `onChange`. Values are colour names
(`"blue"`, `"teal"`, `"green"`, `"lime"`, `"orange"`, `"red"`, `"pink"`, `"purple"`, `"gray"` or `"slate"`). Pass an empty string
when no colour is selected.

The colours come from the design system and cannot be customised. Use `palette` to choose between the `"rich"` (default) and
`"muted"` palettes; the two cannot be combined in one picker. Use `colors` to offer a subset of the palette.

## Keyboard interaction

`ColorPicker` uses the same keyboard interaction as [Select](../?path=/docs/select--docs#keyboard-interaction). Typing a character
selects the next colour whose name starts with it.

## Testing

`ColorPicker` is built on `Select`. If you test it in JSDOM, call `setupSelectMocks` from `carbon-react/lib/components/select`
before rendering. See the [Select testing guidance](../?path=/docs/select--docs#testing).
