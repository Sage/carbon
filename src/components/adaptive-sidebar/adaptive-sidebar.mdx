# Adaptive Sidebar

The `AdaptiveSidebar` component renders a non-modal sidebar, or a modal sidebar in small screens, that can be used to display content alongside the main content of a page. 

## Contents

- [Quick Start](#quick-start)
- [Examples](#examples)
- [Props](#props)

## Quick Start

```javascript
import AdaptiveSidebar from "carbon-react/lib/components/adaptive-sidebar";
```

## Examples

### Default

The `AdaptiveSidebar` component should be rendered as a sibling of the main content within a container with `display: flex` and `flexDirection: row` to ensure proper layout.
The `open` prop can be used to control the visibility of the sidebar programmatically.

We **strongly** recommend setting an accessible label using `"aria-label"` or `"aria-labelledby"` on the component to ensure it is properly announced by screen readers when rendered as a modal. 

<Canvas of={AdaptiveSidebarStories.Default} />

### With Custom Width

By default the width of the component is `320px`, but it can be customised by passing any valid CSS value via the `width` prop.

<Canvas of={AdaptiveSidebarStories.WithCustomWidth} />

### With Custom Height

By default the height of the component is `100%`, but it can be customised by passing any valid CSS value via the `height` prop.

### Variants

The component can be rendered with different visual styles by using the `variant` prop, which accepts "standard" (default), "alt", and "inverse".

### Adaptive Breakpoint

When the viewport width is less than the `adaptiveBreakpoint` prop value, the `AdaptiveSidebar` component will be rendered as a modal sidebar.
By default, the `adaptiveBreakpoint` prop is set to `768px`, but it can be customised by passing the desired pixel breakpoint as a number.

<Canvas of={AdaptiveSidebarStories.AdaptiveBreakpoint} />

### Render As Modal

To render the component as a modal regardless of the viewport size, set the `renderAsModal` prop to `true`.

<Canvas of={AdaptiveSidebarStories.RenderAsModal} />

### Hidden

In instances where the component should not be visible but still remain in the DOM, the `hidden` prop can be used to hide the component from view.
This can be useful when state needs to be preserved while the component is temporarily hidden from view.
