### Menu position

By default, the menu will open aligned to the "right" of the main button, but you can use the `position` prop to change this to the "left". 

Note: The position of the menu will also be automatically adjusted to fit within the viewport.

<Canvas of={MultiActionButtonStories.Position} />

### Full width

You can use the `fullWidth` prop to make the menu match the Multi Action Button's width.

<Canvas of={MultiActionButtonStories.FullWidth} />

### Menu width

You can use the `menuWidth` prop to set a custom width with any valid CSS width value.

<Canvas of={MultiActionButtonStories.FullWidth} />

### (Deprecated) Custom width

The `width` prop has been deprecated and will be removed in a future version. Please use `menuWidth` instead.

Numbers from 0-1 are converted to percentage widths. Numbers greater than 1 are converted to pixel values.
String values are passed as raw CSS values. `size` prop can still be used to set desired height.

<Canvas of={MultiActionButtonStories.CustomWidth} />

### (Deprecated) Button types

The `buttonType` prop has been deprecated and it will be removed in a future version. Please use `variantType` instead.

### (Deprecated) Subtext

The `subtext` prop has been deprecated and it will be removed in a future version. 

Subtext only works when `size` is `large`

<Canvas of={MultiActionButtonStories.Subtext} />

### (Deprecated) Button text alignment

The `align` prop has been deprecated and it will be removed in a future version. 

Use the `align` prop to change the alignment of the text in the menu Buttons.

| Method Name           | Description                               |
| --------------------- | ----------------------------------------- |
| `focusMainButton()` | Programmatically focuses the main button. |
