```javascript

  Menu,
  MenuItem,
  MenuDivider,
  MenuSegmentTitle,
```

## Examples

### Default

To use this component, pass the desired list of `MenuItem` as children of `Menu`. Pass the desired content of the `MenuItem` as children.

> **Note**: To ensure a `MenuItem` is interactive, it should either have an `href`, `onClick` or `submenu` prop, or contain another focusable Carbon component. 
Without one of these, the item will not be keyboard-focusable or interactive, affecting accessibility for keyboard and screen reader users.

<Canvas of={MenuStories.Default} />

### Black Variant

To render this component as the black variant, set the `variant` prop to `"black"` on the `Menu` component.

<Canvas of={MenuStories.BlackVariant} />

### Selected MenuItem

To mark a `MenuItem` as currently selected, pass the `selected` prop to the `MenuItem`.
The `aria-current` attribute should be provided alongside this prop to indicate assistive technology users which item is currently selected.

<Canvas of={MenuStories.SelectedMenuItem} />

### With Submenu

To render a submenu, pass the `submenu` prop to a `MenuItem` and provide the submenu items as children.
The `submenu` prop accepts a string or a React node to render as the submenu title.

To further customise submenu layout and behavior, the following props are available on `MenuItem` with a submenu:
- `submenuMaxWidth`: Sets the maximum width of the submenu when open.
- `submenuMinWidth`: Sets the minimum width of the submenu when open.
- `submenuDirection`: Controls the direction in which the submenu opens. Accepts `"left"` or `"right"`.
- `clickToOpen`: If set to `true`, the submenu will open on click instead of hover.
- `showDropdownArrow`: Controls the visibility of the dropdown arrow for the submenu.

> **Note**: If providing a React node as the title of the submenu, please ensure that no interactive elements are included within it as 
this would likely interfere with the submenu's keyboard navigation and accessibility.

<Canvas of={MenuStories.WithSubmenu} />

### With Alternate Variant

`MenuItem` supports an alternate colour variant, which can be set by passing the `variant` prop to `"alternate"`.

<Canvas of={MenuStories.WithAlternateVariant} />

### Menu Divider

The `MenuDivider` component can be used to render a horizontal divider between `MenuItem` components within a submenu, 
helping to visually separate groups of menu items.
The size of the divider can be set via the `size` prop, which accepts `"default"` or `"large"`.

<Canvas of={MenuStories.WithMenuDivider} />

### Segment Title

The `MenuSegmentTitle` component can be used to add a non-interactive segment title within a submenu. 
To use this component, pass the `text` prop to specify the segment title and pass the desired `MenuItem` components as children.

This component supports the `variant` prop, which can be set to `"alternate"` to apply the 
alternate colour variant to the title and its children.

<Canvas of={MenuStories.WithSegmentTitle} />

### Scrollable Block

The `ScrollableBlock` component can be used to create a scrollable area within a submenu, 
allowing any number of `MenuItem` components to be displayed within a fixed height container.
The height of the scrollable area is controlled by the `height` prop passed to the `ScrollableBlock` component.

This component supports the `variant` prop, which can be set to `"alternate"` to apply the 
alternate colour variant to its children.

<Canvas of={MenuStories.WithScrollableBlock} />

#### Scrollable Block with Parent

The `parent` prop can be passed to the `ScrollableBlock` component to render a scrollable sublist of a parent item. 
This enables to create a semantic relationship between the parent item and the scrollable block. 

<Canvas of={MenuStories.ScrollableBlockWithParent} />

### Text Overflow

By default, `MenuItem` with text that exceeds the available width will wrap onto multiple lines. 
To instead truncate the text with an ellipsis, you can use the `maxWidth` prop on `MenuItem` to define the maximum width of the item.

<Canvas of={MenuStories.TextOverflow} />

### Focusing MenuItems Programmatically

The `MenuItemHandle` type provides an imperative handle for programmatic control over `MenuItem`. 
Using a `ref`, you can access its `focus()` method to set focus on the `MenuItem` as needed.

> **Note**: The `focus()` method will only work on interactive elements. 

<Canvas of={MenuStories.ProgrammaticFocus} />

### Fullscreen Menu

To render a fullscreen `Menu`, pass the `MenuFullscreen` component as a child of `Menu` and the desired `MenuItem` components as children. 
A `MenuItem` can be used as a trigger to open the fullscreen menu, which can be passed as a direct child of `Menu`.
The `onClose` and `isOpen` props can be used to control the visibility of the fullscreen menu.

Please note that the `"alternate"` variant and/or the `maxWidth` prop will not be applied to any components within a `MenuFullscreen`.

<Canvas of={MenuStories.FullscreenMenu} />
