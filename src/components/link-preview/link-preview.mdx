## Quick Start

```javascript
import LinkPreview from "carbon-react/lib/components/link-preview";
```

This component is intended to provide a preview of a given Link within either `TextEditor` or `Note` components. 
- To see an example of how this can be used within `TextEditor`, please see [this example](../?path=/docs/text-editor--docs#with-link-previews).
- To see an example of how this can be used within `Note`, please see [this example](../?path=/docs/note--docs#with-previews).

## Examples

### Default

To use this component, pass a `url` prop with the link you want to preview. 
A `title`, `description` and `image` can also be passed to provide additional context for the link, 
if no `image` is provided, a default placeholder will be used.

By default, the component will be rendered as an anchor element and will navigate to the provided `url` when clicked.

<Canvas of={LinkPreviewStories.Default} />

### Loading State

If no `url` is passed or the `isLoading` prop is true, the component will display in a loading state. 
When in this state, the component will render as a `div` element.

<Canvas of={LinkPreviewStories.LoadingState} />

### With Close Button

If the component is rendered as a `div` element, it is possible to pass an `onClose` callback which will render a close button and pass the callback to it. 

<Canvas of={LinkPreviewStories.WithCloseButton} />

### Sizes

The `size` prop can be used to control the size of the component.
