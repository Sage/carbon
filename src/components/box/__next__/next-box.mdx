# Next Box

Basic component that gives access to a number of styling options. Should be used to achieve more precise layouts when required. Gives access to Spacing, Color, Layout and FlexBox attributes.

## Quick Start

Import the box component to start using

```javascript
import NextBox from "carbon-react/lib/components/box/__next__";
```

## Spacing tokens

Numeric spacing props resolve directly to literal pixels, so `<NextBox p={24} />`
applies `padding: 24px` and `<NextBox p={3} />` applies `padding: 3px`.

| Token                     | Alias  | Example pixel value | Alias CSS value                   |
| ------------------------- | ------ | ------------------: | --------------------------------- |
| `global.space.none`       | `none` |                 `0` | `var(--global-space-none)`        |
| `global.space.layout.3XS` | `3xs`  |                 `8` | `var(--global-space-layout-3-xs)` |
| `global.space.layout.2XS` | `2xs`  |                `16` | `var(--global-space-layout-2-xs)` |
| `global.space.layout.XS`  | `xs`   |                `24` | `var(--global-space-layout-xs)`   |
| `global.space.layout.S`   | `s`    |                `32` | `var(--global-space-layout-s)`    |
| `global.space.layout.M`   | `m`    |                `40` | `var(--global-space-layout-m)`    |
| `global.space.layout.L`   | `l`    |                `48` | `var(--global-space-layout-l)`    |
| `global.space.layout.XL`  | `xl`   |                `56` | `var(--global-space-layout-xl)`   |
| `global.space.layout.2XL` | `2xl`  |                `64` | `var(--global-space-layout-2-xl)` |
| `global.space.layout.3XL` | `3xl`  |                `72` | `var(--global-space-layout-3-xl)` |
| `global.space.layout.4XL` | `4xl`  |                `80` | `var(--global-space-layout-4-xl)` |

Use a numeric value when explicit pixel CSS is required. Use a short token alias
when the CSS declaration should retain the token variable, for example
`<NextBox p="3xs" />` emits `padding: var(--global-space-layout-3-xs)`.

## Token alias interface

Every NextBox spacing prop accepts a numeric value, a short token alias,
or any valid CSS string. The token aliases are lowercase and exact:

```ts
type SpacingToken =
  | "none"
  | "3xs"
  | "2xs"
  | "xs"
  | "s"
  | "m"
  | "l"
  | "xl"
  | "2xl"
  | "3xl"
  | "4xl";
```

Use them with shorthand (`m`, `p`, `mt`, `px`), longhand (`marginTop`,
`paddingLeft`), or axis aliases (`marginX`, `marginY`, `paddingX`, `paddingY`):

```jsx
<NextBox p="m" px="2xs" marginY="xl" />
```

Each alias emits its matching `var(--global-space-...)` CSS variable in the Styles
tab; the Computed tab shows the resolved pixel value.

Full token paths such as `global.space.layout.3XS` are not aliases. Use the short
alias from the table above, a numeric value, or an explicit CSS string.

CSS strings are also supported when a more granular value is needed, including CSS
variables, calculations, percentages, and negative margins. For example,
`<NextBox mt="calc(100% - 24px)" ml="-8px" />` passes those values through to CSS.

## Migrating spacing values

The spacing prop names are unchanged. Continue to use shorthand props such as
`m`, `p`, `mt`, and `px`; longhand props such as `marginTop` and `paddingLeft`;
and the `marginX`, `marginY`, `paddingX`, and `paddingY` aliases.

Legacy `Box` spacing props treated a number as an index into the theme spacing
scale. With the base theme, migrate those values to the corresponding
global-space variable before using NextBox:

| Legacy numeric index | Previous spacing | Use now                           |
| -------------------: | ---------------: | --------------------------------- |
|                  `0` |            `0px` | `var(--global-space-none)`        |
|                  `1` |            `8px` | `var(--global-space-layout-3-xs)` |
|                  `2` |           `16px` | `var(--global-space-layout-2-xs)` |
|                  `3` |           `24px` | `var(--global-space-layout-xs)`   |
|                  `4` |           `32px` | `var(--global-space-layout-s)`    |
|                  `5` |           `40px` | `var(--global-space-layout-m)`    |
|                  `6` |           `48px` | `var(--global-space-layout-l)`    |
|                  `7` |           `56px` | `var(--global-space-layout-xl)`   |
|                  `8` |           `64px` | `var(--global-space-layout-2-xl)` |
|                  `9` |           `72px` | `var(--global-space-layout-3-xl)` |
|                 `10` |           `80px` | `var(--global-space-layout-4-xl)` |

For example:

```jsx
// Before: legacy Box numeric values are theme spacing indexes
<Box p={1} />
<Box p={2} />
<Box p={3} />

// After: NextBox numeric values are explicit pixels
<NextBox p={8} />
<NextBox p={16} />
<NextBox p={24} />
```

Short token aliases are also available when you want the CSS declaration to retain
the design token:

```jsx
<NextBox p="none" />
<NextBox p="3xs" />
```

> **Important:** `8` is ambiguous. It previously meant spacing index `8` (64px),
> but now resolves to the approved explicit value of 8px. Migrate existing
> `p={8}` usage to `p={64}` when the intended spacing is 64px.

Use CSS strings for CSS variables, percentages, and calculations:

```jsx
<NextBox mt="-8px" p="var(--spacing300)" pb="5%" />
<NextBox mx="calc(100% - 24px)" />
```
