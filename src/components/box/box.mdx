# Box

Basic component that gives access to a number of styling options. Should be used to achieve more precise layouts when required. Gives access to Spacing, Layout and FlexBox attributes.

## Contents

- [Quick Start](#quick-start)
- [Examples](#examples)
- [Props](#props)

## Quick Start

Import the box component to start using

```javascript
import Box from "carbon-react/lib/components/box";
```
