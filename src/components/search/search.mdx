it provides a familiar input pattern with a built-in search button.

## Examples

### With Dropdown

The `Search` component supports a popover dropdown for displaying structured search results or suggestions.
This is controlled via these props on `Search`:

- **`open`** — a boolean that controls whether the dropdown is visible. Set this to `true` when there
  are results to display (e.g. filtered matches).
- **`maxHeight`** — an optional max-height value for the dropdown list. Use this to override the default
  size-based list height.
- **`minQueryLength`** — minimum number of typed characters used by the built-in results announcement logic.
  Defaults to `3`.
- **`listData`** — an array of `SearchListGroup` objects that define the grouped content of the dropdown.
- **`onListItemSelect`** — a callback fired when the user chooses an item. It receives the item's `value`
  string, which you can use to update the input value.
- **`onClose`** — a callback fired when the dropdown requests to close (e.g. Escape, click-away, item click).
  It receives the optional `event` and selected `value`. Use this to update your own state and set
  `open={false}` when required.

#### `SearchListGroup`

Each group in `listData` has the following shape:

| Property  | Type               | Required | Description                                         |
| --------- | ------------------ | -------- | --------------------------------------------------- |
| `heading` | `string`           | Yes      | The heading label rendered above the group's items. |
| `icon`    | `React.ReactNode`  | No       | An optional icon rendered alongside the heading.    |
| `items`   | `SearchListData[]` | Yes      | The list of items within the group.                 |

#### `SearchListData`

Each item within a group has the following shape:

| Property       | Type                     | Required | Description                                              |
| -------------- | ------------------------ | -------- | -------------------------------------------------------- |
| `value`        | `string`                 | Yes      | The value passed to `onListItemSelect` when chosen.      |
| `label`        | `string`                 | Yes      | The primary display text for the item.                   |
| `labelPrefix`  | `string`                 | No       | An optional prefix rendered before the label.            |
| `subtext`      | `string`                 | No       | Secondary text rendered below the label.                 |
| `selectedIcon` | `boolean`                | No       | Enables selected-state tick icon behavior for that item. |
| `leading`      | `React.ReactNode`        | No       | Optional leading slot content, e.g. an icon or avatar.   |
| `disabled`     | `boolean`                | No       | When `true`, the item is non-interactive.                |
| `id`           | `string`                 | No       | Optional `id` attribute for the list item element.       |
| `onClick`      | `(event, value) => void` | No       | Optional per-item click handler.                         |

## Ref methods

`Search`'s forwarded ref exposes the following imperative methods:

| Method Name     | Description                                 |
| --------------- | ------------------------------------------- |
| `focus()`       | Programmatically focuses the search input.  |
| `focusButton()` | Programmatically focuses the search button. |
