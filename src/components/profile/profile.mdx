A profile presents basic information about a person, user, or organization. It displays a [Portrait](../?path=/docs/portrait--docs) and some details.

**Category:** Feedback

## Contents

- [Quick Start](#quick-start)
- [Examples](#examples)
- [Props](#props)

## Quick Start

```javascript
import Profile from "carbon-react/lib/components/profile";
```

## Examples

### Default

The `email` prop automatically surfaces the `href` attribute with `mailto:`. This will enable
users to send a new email within their default email program to the email address. To display an
email address without `mailto:`, use custom content instead of providing the `email` prop.

<Canvas of={ProfileStories.Default} />

### Variant

The `variant` prop can be passed to apply a colour variant to the Portrait.
See the [Portrait](/docs/portrait--docs) docs for more information on variant.

<Canvas of={ProfileStories.Variant} />

### Src

To use an image, simply pass any valid image URL as a `src` prop.

<Canvas of={ProfileStories.Src} />

### Sizes

Use the `size` prop to choose a Profile size from `XS`, `S`, `M`, `ML`, `L`, `XL`, or `XXL`.

<Canvas of={ProfileStories.Sizes} />

### With margin

Margins can be applied to the `Profile` component using styled-system.
To see a full list of available margin props, please visit the props table at the bottom of this page.

[Visit Props Table](#props)

<Canvas of={ProfileStories.WithMargin} />

### Responsive Example

Use this example when the Profile size needs to adapt to the viewport using media queries.

<Canvas of={ProfileStories.Responsive} />

### With custom content

Custom content is stacked below the profile details on the right-hand side.
The `Box` component has been used to apply width, height, shadow.

<Canvas of={ProfileStories.WithCustomContent} />

The `foregroundColor` prop has been deprecated and will be removed in a future version. Please use `variant` instead.
