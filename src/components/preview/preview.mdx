# Skeleton

Skeletons indicate that content is loading.

## Contents

- [Quick Start](#quick-start)
- [Examples](#examples)
- [Props](#props)

## Quick Start

```javascript
import Skeleton from "carbon-react/lib/components/skeleton";
```

### With Custom Width

You can use the `width` prop to specify the width of the Skeleton. It fills the available width by default.

<Canvas of={PreviewStories.WithWidth} />

### With Custom Height

You can use the `height` prop to specify a custom CSS height or one of the presets: `h1` (38px), `h2` (30px), `h3` (26px), `h4` (23px), `paragraph` (21px), or `button` (40px).

<Canvas of={PreviewStories.WithHeight} />

### Shapes

Choose `circle`, `rectangle-curved`, or `rectangle-moderate` with the `shape` prop. The default is `rectangle-moderate`.

Use `lines` to render multiple Skeletons. Circles remain circular: their width always follows their height, so `width` is ignored for circles.

### Disable Animation

The animated gradient moves from left to right. Set `disableAnimation` to render a solid static placeholder; animation is also disabled when the user prefers reduced motion.
