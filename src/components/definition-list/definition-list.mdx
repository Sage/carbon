### Spacing

`spacing="small"` applies 4px of bottom padding to each pair, producing 4px between adjacent pair content. The default `spacing="large"` applies 12px, producing 12px between adjacent pair content. Top padding is only applied, matching the bottom padding, when `divider` is set, so each divider is evenly spaced from the content above and below it.

<Canvas of={DefinitionListStories.Spacing} />

### Multiple descriptions

Each term can have one or more native `<Dd />` descriptions.

<Canvas of={DefinitionListStories.MultipleDescriptions} />

Each `<Dd />` supports its own `rightChildren` independently, so multiple descriptions under one term can each have their own supplementary element without needing to compose with `Box`.

<Canvas of={DefinitionListStories.MultipleDescriptionsWithRightChildren} />

### With right children

Use the `rightChildren` prop on `Dd` to render a supplementary element, such as a Pill or Link, aligned to the right of the description.
