The Batch Selection component is used to display the number of selected items and provide actions that can be performed on those items. 
It is typically used in conjunction with a list or table of items, allowing users to select multiple items and perform batch actions on them.

## Contents

## Quick Start

To use Batch Selection, import the component and pass the desired content as children.

```javascript
import BatchSelection from "carbon-react/lib/components/batch-selection";
```

## Examples

### Default

By default, the component displays the number of selected items, the provided children, and the dismiss button in a single row within a tile.

Set the `selectedCount` and `totalItems` props to define the selection state. To show the dismiss button, pass a callback to the `onDismiss` prop.

<Canvas of={BatchSelectionStories.Default} />

### Small Screen

To adjust the component's layout for small screens, set the `smallScreen` prop to `true`.

This renders a row containing the selected item count and close button, followed by a divider and a second row containing the provided children.

<Canvas of={BatchSelectionStories.SmallScreen} />

### Example Implementation

Please see below an example implementation of how the component can be used to follow the recommended DS pattern for this component, using the `Button` and `Divider` components to create the desired layout.

The `useMediaQuery` hook can be used to switch between the default and small-screen layouts, as well as adjusting the layout of the children to fit the available space.
For more information, see the [useMediaQuery documentation](../?path=/docs/documentation-hooks-usemediaquery--docs).
