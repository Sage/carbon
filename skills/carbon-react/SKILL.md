# Carbon Component Catalog

Open `index.md` to select a component, then load that component's file. Open only the linked examples needed for the task.

Component files combine authored selection guidance with source-derived imports, props, defaults, and deprecations. Components with curated examples link to selected Storybook stories and omit their playground; other components retain their generated Storybook examples.

- Open `references/docs/usage.md` for package setup and basic usage.
- Open `references/docs/installation.md` when installing or configuring Carbon React.
- Open `references/docs/recommended-practices.md` for project-wide Carbon conventions.
- Open `references/docs/usage-with-routing.md` when Carbon links integrate with routing.
- Open `references/docs/extending-styles-using-styled-components.md` when extending component styles.
- Open `references/docs/colors.md` when choosing Carbon colours or tokens.
- Open `references/docs/i18n.md` when translating component-provided text.
- Open `references/docs/deprecation-migration.md` when a selected component or prop is deprecated.

Before finishing, confirm that imports and props match the component file and that deprecated APIs are either avoided or handled using the migration guidance.
